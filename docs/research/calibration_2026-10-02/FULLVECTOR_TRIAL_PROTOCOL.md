# Bounded full-vector development trial

Declared before live scoring, 2026-10-02. First trial: retained 12054000,
seed 42, the separately sealed 15-point design in fullvector_preflight_v1.json.
This exposed calibrated model is an integration case, not an unseen basin.
The other two designs remain prepared until this integration case is assessed.

Open all 14 retained active/weak controls as explicit scalar edits. Excluded
controls and all other model inputs remain fixed in the sealed warm source.
Historical screening is eligibility evidence only, not surrogate training data
and not a certified new end-to-end screening cost.

Objective: explicit raw KGE weight 1, finite NSE/KGE/PBIAS, absolute PBIAS at
most 30%, and the reported calibration-process categorical proxy. Use exact
receipt-sealed training output; simulate 2007–2015, score 2010–2015. No temporal
validation score is revealed in this trial. No objective or gate threshold changes.

DDS and optional constrained GP receive the same 15 physical initial results,
charged to both ledgers. Each then has exactly one search request, followed by
one forced-fresh training check if an admissible measured winner exists. If no
DDS incumbent exists, its seed retry consumes its sole search request; it is
not described as an adaptive improvement. Per-arm cap 18 reserves one temporal
request that remains unused. Maximum physical callbacks are 19; maximum charged
requests in this training phase are 34. Failures consume budgets; no free retries.

Keep one engine thread, 300-second call timeout, prior GP defaults and separate
arm work directories. Record fit/proposal warnings and costs, callback costs,
actual successful receipts, full ledger events, source/engine/observation/code
identities and fresh parity. Execute DDS before GP as a fixed integration order;
this order is not a balanced elapsed-performance experiment.

Stop on configuration/provenance/adapter defects; retain checkpoints and charges.
Do not resume an optimizer trajectory by silently rereading partial ledger data.
Numeric/engine failures retain failed observations and can complete with no
winner. A rank-sufficient input design can lose usable rank after failures;
report finite/feasible training counts separately from proposed-design rank.

This tiny adaptive budget cannot establish calibration efficiency, convergence,
new scientific contribution or superiority. No model promotion or software
public push is authorized by this trial. Repeated seeds, a space-filling-only
comparator and broader/new basin evaluation remain necessary for performance
claims. Temporal periods previously exposed in PE1 are development transfer
checks, even when excluded from this particular optimizer search.
